# Project Decisions Memory: HRU Basud

- [active 2026-10-28] Project Baseline Stack: Next.js 16+ (App Router) with React 19, Tailwind CSS v4, Bun runtime, and Drizzle ORM. Turbopack default for development and build. Reason: Modern, fast GovTech standard stack aligned with LGU municipal management system standards. Source: Workspace rules. Applies to whole project.
- [active 2026-10-28] Next.js 16 Asynchronous Request APIs: Mandatory asynchronous access (`await params`, `await searchParams`, `await cookies()`, `await headers()`). Reason: Synchronous access removed in Next.js 16. Source: Workspace rules. Applies to all App Router pages and route handlers.
- [active 2026-10-28] Strict 4px Grid Sizing: All spacing, padding, margin, gap, width, height, border radius, and icon sizes must be divisible by 4px. Use whole-number Tailwind steps (`p-1`=4px, `p-2`=8px, `p-3`=12px, `p-4`=16px, `p-6`=24px, `p-8`=32px). Zero half-steps and zero arbitrary non-4-divisible pixel values. Reason: `.agents/rules/ui-design.md`. Source: Workspace rules. Applies to all UI components.
- [active 2026-10-28] Mobile-First Responsiveness: Every page and component must function seamlessly at 360px (mobile), 768px (tablet), and 1280px (desktop) with zero horizontal page scroll. Wide tables scroll inside `overflow-x-auto`. Minimum 40px tap targets on 4px grid. Navbar collapses on mobile. Reason: `.agents/rules/ui-design.md`. Source: Workspace rules. Applies to all components and pages.
- [active 2026-10-28] DataGrid / DGV Standards: Tables must present a scannable summary (3-5 columns on desktop, 2-3 on mobile). Every row must be clickable and activate an Action Options modal (`rowActions`) with imperative action labels, descriptions, and Phosphor icons. Pagination and informative empty states are mandatory. Reason: `.agents/rules/component-structure.md`. Source: Workspace rules. Applies to all table / list views.
- [active 2026-10-28] Project Documentation Authority & Precedence: `.agents/rules/project-documentation.md` establishes strict hierarchy: 1. `defense-feedback.md`, 2. Approved Proposal PDF, 3. `_suggestions.md`, 4. System Diagrams (`ERD.png`, `DFD_0.png`, `DFD1.png`, `SysArch.png`), 5. Workspace rules. Reason: Official defense panel and proposal scope compliance. Source: `.agents/rules/project-documentation.md`. Applies to all tasks.
- [active 2026-10-28] Domain Scope (HRU Basud): Human Resource Unit of the Municipality of Basud, Camarines Norte. Core system scope comprises Employee Master & 201 File Registry (Plantilla, Casual, JO/COS), Leave Administration & Credits Ledger (CSC Form 6), Attendance & DTR Logging (CSC Form 48), Recruitment & Selection (CSC QS), Performance Commitment (SPMS / IPCR), and Official Service Records / COE issuance. Reason: Project charter definition. Source: System design. Applies to all modules and schemas.
